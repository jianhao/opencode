# 01 · 产品与交互

> 目标：打开桌面端就看到「今天该干什么、卡在哪」，扫一眼就够，不点开第三个页面。
> 参考 WorkBuddy 的「左列表 + 右结果」，但去掉对话、附件树、卡片瀑布。

## 1. 入口

### 1.1 Home 右栏切换

`Home` 的右栏顶部放一个 28px 高的分段控件：

```text
[ 工作台 ]  [ 最近会话 ]
```

- 默认选中「工作台」。选择写进工作台自己的 `state`（namespace `workbench`，key `view`），不动 `layout` schema，下次启动记住。
- 「最近会话」就是现有 `HomeSessions`，一行代码不改，只是被条件渲染。
- 切换不做路由跳转，不刷新数据。

### 1.2 titlebar

不改。Home 按钮还是回 Home；工作台是 Home 的默认视图，所以 Home 按钮 = 回工作台。

不新增「工作台」图标按钮：两个入口指向同一处会让人犹豫哪个才是正的。

### 1.3 宽度

| 视图 | 内容宽度 |
| --- | --- |
| 最近会话 | 保持 `max-w-[1080px]`（280 + 720 + gap） |
| 工作台 | `max-w-none`，左右 padding 20–24px，三栏铺满 |

切换视图时容器宽度变化要做 150ms 的 `max-width` 过渡，避免跳动；`prefers-reduced-motion` 下直接切。

## 2. 布局

### 2.1 三栏

```text
┌─────────────┬──────────────────────────────────────────┬──────────────────────┐
│ 项目 240    │ 工具条                                    │ 详情 400             │
│             ├──────────────────────────────────────────┤                      │
│ ● 全部      │ 统计条                                    │ 云效号 标题           │
│   crew-web… │ ─────────────────────────────────────    │ [概览][映射][上下文]  │
│   crew-app… │ 筛选：搜索 · 项目 · 航司 · 只看未绑定      │                      │
│   crew-port…│ ─────────────────────────────────────    │ 内容区（滚动）        │
│             │ ▸ 列表（56px/行，滚动）                    │                      │
│             │                                          │ 底部动作              │
└─────────────┴──────────────────────────────────────────┴──────────────────────┘
```

- 列宽：`240px | minmax(0,1fr) | 400px`。
- 三栏之间用 1px `--v2-border-border-base` 分隔，不用卡片嵌套、不用阴影堆叠。
- 只有外层 Home 面板有 `--v2-elevation-raised`，内部一律平面。

### 2.2 断点

| 宽度 | 行为 |
| --- | --- |
| ≥ 1280 | 三栏 |
| 1024–1279 | 详情缩到 360，项目栏缩到 200 |
| 768–1023 | 项目栏隐藏，项目筛选移到筛选行的「项目」下拉；详情变成右侧抽屉（点击行打开） |
| < 768 | 单栏：统计条 + 列表；详情全屏推入；筛选收进抽屉 |

V1 只为「看得清」。手机上不追求改代码。

## 3. 工具条

高度 48px，上下 padding 8px：

```text
[工作台|最近会话]                               ● 2 分钟前  ↻  ◎ 自动 5m  ＋
```

- 左侧分段控件，`h-7`，圆角 6，选中项 `bg-v2-background-bg-layer-01` + `text-v2-text-text-base`，未选中 `text-v2-text-text-muted`。
- 右侧：
  - 同步指示：6px 圆点 + 相对时间。状态色只用三态：正常 `--v2-state-fg-success`，过期 `--v2-state-fg-warning`，失败 `--v2-state-fg-danger`。刷新中圆点换成 12px 的旋转环。
  - `↻` 图标按钮：立即刷新，请求中禁用并旋转。
  - 自动刷新：开关 + 「5m」标签，点开可选 5 / 10 / 15 / 30 分钟。
  - `＋` 图标按钮：手动添加工作项。
- 不加标题文字「云效工作台」，Home 的语义已经够了；多余标题只会占高度。

## 4. 统计条

不是 KPI 卡片。一条 44px 高的横条，四个数字用竖线分隔：

```text
  12        5          3          4
 待处理    可做       需澄清     阻塞
```

- 数字 20px medium，`font-variant-numeric: tabular-nums`，颜色 `--v2-text-text-base`。
- 标签 12px，`--v2-text-text-muted`。
- 整条可点：点某一组等于加筛选；再点取消。选中时该组数字变 `--v2-text-text-accent`，底部 2px 主色下划线。
- 下面是 3px 高的分布条，按占比分四段（可做绿 / 需澄清黄 / 阻塞红 / 其余 `--v2-border-border-strong`），圆角 2。这是唯一的「视觉亮点」，不喧哗但一眼看出健康度。
- 0 值显示 `0` 并降为 `--v2-text-text-faint`，不隐藏（隐藏会让人以为没统计）。

## 5. 筛选

一行，高度 36px：

| 控件 | 行为 |
| --- | --- |
| 搜索框 | 云效号 / 标题 / 项目 / 航司，本地过滤，200ms 防抖 |
| 项目 | 多选，来自 `settings.projects` 的 key；左栏可见时隐藏这个 chip（左栏已经在做同一件事），左栏折叠后才出现 |
| 航司 | 多选，来自 `airline_environment` 去重 |
| 只看未绑定 | 开关 |
| 排序 | 下拉：优先级 → 更新时间（默认）/ 更新时间 / 创建时间 |

- 筛选项存 `state` namespace `workbench` 的 `view` key，重开还保留。
- 有筛选时右侧出现「清除」，点击一次清空。
- 筛选后为空：列表区显示「当前筛选下没有工作项」+「清除筛选」按钮，不显示整页空状态。

## 6. 列表

### 6.1 行结构（56px）

```text
┌──────────────────────────────────────────────────────────────────────┐
│ TG-3223  ●P1   Flight Log 附件上传后预览空白              需澄清  ·   │
│               crew-web-vue-3.0 · auto-test · TG · 3 天前    💬4 📎2  │
└──────────────────────────────────────────────────────────────────────┘
```

- 第一行：云效号（12px mono，`--v2-text-text-muted`）· 优先级（12px mono，P0 用 danger 色）· 标题（14px，最多 1 行省略，hover 出全文 tooltip）。
- 第二行：项目 · 分支 · 航司 · 相对更新时间（全部 12px `--v2-text-text-muted`，间隔用 `·`）。
- 右侧：只放可做性标签（12px，`--v2-state-*` 三色底）。评论/附件数量不进列表——每行都是小数字会变成噪音；数量在详情 tab（评论 4）和上下文里看。
- 左侧 2px 选中条 + `bg-v2-background-bg-layer-01`。
- 手动项：云效号位置显示 `手动` 标签（虚线边框），第二行末尾加「手动添加」。不伪装成云效单。

### 6.2 分组

默认不分组（一个平铺列表，按排序规则）。原因：分组会让 12 条变成三段，反而更难扫。

提供「按项目分组」开关（筛选行右侧图标）：分组头 28px，` bg-v2-background-bg-layer-01`，左侧项目名，右侧「N 条 · 可做 M」。

### 6.3 排序

默认：

1. 阻塞 → 需澄清 → 可做（需要人处理的在前）
2. 优先级 P0 → P3
3. `updatedAt` 倒序

手动项参与同样的排序，但永远排在云效项之后（同优先级时）。

## 7. 详情

宽 400，独立滚动，顶部 header 吸顶，底部动作吸底。

### 7.1 头部

```text
TG-3223  [P1] [缺陷]                       [需澄清]
Flight Log 附件上传后预览空白
TG · 泰国国际航空 · 待处理 · 3 天前更新
```

- 标题 16px medium，最多 2 行。
- 副行 12px muted，不重复标题里已有的项目名。

### 7.2 Tabs

```text
[ 概览 ] [ 映射 ] [ 上下文 ] [ 评论 4 ]
```

40px 高，选中项 2px 主色下划线，其余 muted。切 tab 不重新请求。

**概览**

- 元信息：两列网格（航司 / 项目 / 空间 / 负责人 / 创建 / 更新），12px，键 muted、值 base。
- 描述：正文富文本转纯文本，前 800 字，超出显示「查看完整正文」（外链云效）。
- 可做性原因：每条一行，前置 6px 点（绿 pass / 黄 risk / 红 block）。
- 还缺什么：`--v2-state-bg-warning` 底的小块，最多 3 条，超出折叠。

**映射**

竖向链路，每行 40px：

```text
● 云效空间   Crew Web 前端           已确认
│
● 代码项目   crew-web-vue-3.0        enabled
│
● 本地目录   /…/pier/crew-web-vue-3.0  存在
│
● 工作区     main                     可切换 ▾
│
● 环境分支   auto-test               环境表
│
● 本地分支   auto-test               一致
│
● 工作区状态 clean                   干净
```

- 正常点用 `--v2-state-fg-success`，警告用 warning，失败用 danger。
- 「工作区」行是可交互的：下拉列出该项目所有存在的主目录与 worktree（`crew-app-front-3.0-worktree`、`…-worktree1`），切换只改展示，不改磁盘。
- 分支不一致：整行琥珀，文案「本地在 X，环境表是 Y」，不做自动切换。
- 底部两个按钮：`重新扫描`（只重跑本地检查）、`去设置`。

**上下文**

- 父项 / 子项 / 关联项：一行一条（云效号 + 标题 + 状态），点击外链。
- 附件：名称 + 大小，点击走现有下载。
- 原始 JSON：折叠，仅设置里打开「调试信息」时显示。

**评论**

- 只读列表：作者 12px medium、时间 12px muted、正文 13px/1.65。
- 不做输入框，不做表情。

### 7.3 底部动作

```text
[ 打开云效 ]  [ 复制云效号 ]              [ 开始处理 · V2 ]
```

- `开始处理` V1 置灰，tooltip「V2 开放」。不做假按钮点了弹提示。
- 手动项没有「打开云效」，换成「编辑」。

## 8. 手动添加工作项

点工具条 `＋` 打开居中对话框（480px）：

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 标题 | 是 | 1–200 字 |
| 云效号 | 否 | 有就填，用于和自己记的单对齐 |
| 项目 | 是 | 来自已配置项目；决定映射和分支 |
| 工作区 | 否 | 默认 main，可选 worktree |
| 分支 | 否 | 空则用项目默认分支 |
| 航司 | 否 | 来自环境表去重 |
| 优先级 | 否 | P0–P3 |
| 链接 | 否 | http(s) |
| 备注 | 否 | 多行 |

- 保存后立即出现在列表顶部（按排序规则落到该在的位置），并标「手动」。
- 手动项不参与云效刷新，不会被覆盖。
- 删除需二次确认；云效项不可删（只能关闭，V1 不做）。

## 9. 视觉规范

### 9.1 用 token，不写色值

全部走 `packages/ui/src/styles/tokens/theme.css` 的语义 token，明暗主题和自定义主题自动生效：

| 用途 | token |
| --- | --- |
| 面板底 | `--v2-background-bg-base` |
| 次级块 / 分组头 / 选中行 | `--v2-background-bg-layer-01` |
| 悬停 | `--v2-overlay-simple-overlay-hover` |
| 分隔线 | `--v2-border-border-base` |
| 正文 | `--v2-text-text-base` |
| 次要 | `--v2-text-text-muted` |
| 更弱 | `--v2-text-text-faint` |
| 链接 / 选中数字 | `--v2-text-text-accent` |
| 可做 | `--v2-state-bg-success` / `--v2-state-fg-success` |
| 需澄清 | `--v2-state-bg-warning` / `--v2-state-fg-warning` |
| 阻塞 | `--v2-state-bg-danger` / `--v2-state-fg-danger` |
| 面板阴影 | `--v2-elevation-raised` |
| 浮层（对话框/抽屉） | `--v2-elevation-floating` |

禁止一次性 hex、禁止自定义蓝、禁止渐变大色块。

### 9.2 字号与行高

用现有工具类，不新造：

| 用途 | 类 |
| --- | --- |
| 详情标题 | `text-16-medium` |
| 列表标题 / 正文 | `text-14-regular` |
| 元信息 / 标签 | `text-12-regular` |
| 云效号 / 分支 | `text-12-mono` |
| 统计数字 | `text-20-medium` + `tabular-nums` |

最小 12px。不用 11px 以下字号（可读性和现有规范都不允许）。

### 9.3 间距

4 的倍数：4 / 8 / 12 / 16 / 20 / 24。行内间距 8，区块间距 12，栏内 padding 16。

### 9.4 圆角与边框

- 面板 10（和现有 Home 面板一致）。
- 行内标签 / 按钮 6。
- 对话框 12。
- 边框统一 1px，不用双线、不用描边+阴影叠加。

### 9.5 动效

- 视图切换 150ms `ease-out`，只动 opacity 和 max-width。
- 行 hover 120ms 背景过渡。
- 刷新指示器旋转 900ms linear。
- `prefers-reduced-motion: reduce` 下全部关闭。

## 10. 状态

| 状态 | 展示 | 动作 |
| --- | --- | --- |
| 首次加载 | 列表 3 条骨架 + 统计条占位 | 无 |
| 有缓存刷新中 | 显示缓存，同步点旋转 | 可继续浏览 |
| 未配置令牌 | 整栏空状态：「先配置云效令牌」 | 打开令牌设置 |
| 令牌失效 | 顶部红色提示条 + 空列表 | 重新配置 |
| 本地服务未连接 | 「本地服务未连接」+ 当前地址 + 重试 | 重试 / 改地址 |
| 没有工作项 | 「没有指派给你的工作项」+ 刷新 | 刷新 |
| 部分项目失败 | 琥珀提示条：「3 个项目拉取失败」可展开明细 | 重试失败项 |
| 项目未绑定 | 行内「未绑定」标签，详情映射链标红 | 去设置 |
| 数据过期 > 10 分钟 | 同步点变琥珀 + 「已过期 N 分钟」 | 刷新 |
| 刷新失败 | 保留旧数据 + 红色提示条 | 重试 |

提示条高 32px，贴在工具条下方，不遮挡操作，不弹 toast（除复制成功）。

## 12. 与现有页面的关系

- 工作台是「我个人的待办作战视图」，不替代 `yunxiao-web` 的工作项列表（高级筛选、批量分析还在那边）。
- 项目列表沿用 Home 现有 `HomeProjects`，不重复造项目侧栏。
- 航司/环境/分支的源头仍在 `frontend-server` 的 `airline_environment`，工作台只读。
- 工作台自己的配置只有：根目录、项目路径、空间绑定、令牌、轮询间隔。

## 13. 原型

[workbench-mockup.html](./workbench-mockup.html)：桌面端三栏、明暗双主题、可点行、可切 tab、可筛选、可添加手动项。

原型只用于对齐视觉和字段密度，不接真实接口。窄屏部分只演示「项目栏隐藏 + 详情让位」，真实实现里详情是抽屉/全屏推入。

### 2.3 V1.0 验收

必须全部满足：

- [ ] 打开桌面端，Home 右栏默认是工作台；切到「最近会话」后功能与改动前完全一致。
- [ ] 未配置令牌时引导清晰；配置后能拉到「指派给我」的需求/任务/缺陷。
- [ ] 20 条真实单与云效页面人工对比：不漏（在白名单内）、不重。
- [ ] 每条单显示：云效号、标题、项目、分支、航司、优先级、可做性、更新时间。
- [ ] 解析不到的项目/分支显示「未绑定 / 分支缺失」，绝不出现猜出来的值。
- [ ] 点行能看详情：正文、映射链、关联项、附件、评论、云效外链。
- [ ] 5 分钟自动刷新；手动刷新立即生效；请求中不重复发。
- [ ] 窗口隐藏暂停定时器；重新可见且超时则立即刷新一次。
- [ ] 停掉 `frontend-server` 显示「本地服务未连接」，不白屏、不连环报错。
- [ ] 单个项目 401/超时不影响其他项目，界面提示可展开。
- [ ] 冷启动 < 8s（7 项目 × 3 类别），有缓存 < 1s。
- [ ] 1280 / 1024 / 768 三档无横向溢出；明暗两套主题都正常。
- [ ] `bun typecheck`（desktop / app）、`bun test`（相关包）、无 console error。

## 4. V2a 改 + 验（15–20 人日）

范围：

- 从工作台选中一条单 → 建任务。
- 主进程建 worktree（`<projectRoot>/.worktrees/<serial>-<shortid>`）+ 分支（`workbench/<serial>-<shortid>`）+ opencode 会话。
- 工作台实时看：状态、Agent 消息、工具调用、文件变更、diff。
- 按项目 `verifyProfile` 跑 `lint / typecheck / unit / build`。
- 证据包：diff stat、命令、退出码、日志、超时原因。
- 人工接受 / 重跑 / 放弃。不做 push、不写云效。

| # | 任务 | 估时 |
| --- | --- | --- |
| V2-1 | 任务表（新 SQLite 表）+ 状态机 + `WorkbenchTask*` RPC | 2d |
| V2-2 | worktree 创建/清理/失败回滚 | 2d |
| V2-3 | opencode 会话接入（启动、prompt、事件流、权限） | 3d |
| V2-4 | 任务面板：实时日志与文件变更 | 2d |
| V2-5 | diff 查看 | 1.5d |
| V2-6 | 验证执行器：白名单、超时、串行 | 3d |
| V2-7 | 证据包 + 验收动作 | 2d |
| V2-8 | 中断 / 恢复 / 孤儿进程回收 | 1.5d |
| V2-9 | 3 条真实需求试跑 | 3d |

验收：

- [ ] 3 条真实需求完成：worktree 隔离、diff 可看、验证有证据。
- [ ] 任务失败/取消后 worktree 可清理，主工作区不受影响。
- [ ] 同一需求不会有两个活跃会话。
- [ ] 进程崩溃或应用重启后，任务状态可恢复或明确标失败，不出现「假运行中」。
- [ ] 验证超时/失败有明确日志，不静默成功。

## 8. 测试计划

- 单元：resolve（8 个分支）、readiness（12 条规则）、settings（损坏 JSON / 越界）、secret（往返 / 降级）、snapshot（排序 / 去重 / 截断）。
- 集成：mock 云效（多项目、401、429、超时）、临时 git 仓库（分支、dirty、remote 不匹配）。
- 组件：列表三态、详情四 tab、空/错状态。
- 手工：20 条真实单、断网、停服务、三档宽度、双主题。

## 9. 回滚

- 只新增 RPC 组和渲染进程模块；出问题把 Home 默认视图改回「最近会话」即可，数据与现有功能不受影响。
- 存储用独立 namespace `workbench`，删掉不影响 `layout` / `drafts`。
- 令牌文件独立，删除即退出登录。

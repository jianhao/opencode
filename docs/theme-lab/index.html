为什么现在显得素

问题不是“缺少颜色”，而是颜色没有承担稳定的语义职责。

01
文字和图标挤在同一灰阶

正文、次要标签和多数图标都接近中灰。建议正文对比度提高到 80% 以上，图标只承担对象或动作提示。

02
新图标默认没有启用

defaultSettings.general.newIcons = false，并且 terminal、branch、MCP 等仍未迁移。视觉上会像“又退回去了”。

03
语义色没有进入日常动作

现有 token 已有 agent、状态和 diff 色，但侧栏、标签页和常用图标仍主要使用 muted 灰。应让分类色稳定出现，而非大面积铺色。

action / accent agent / brand-2 warning / warm success info / object
建议选一套作为发布主推，其余作为可选主题；不改掉现有默认主题。 目标：内容面克制，交互面有材料感，而不是给所有组件加光泽。
